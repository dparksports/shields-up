Audience: scientists, researchers, students, government employees, concerned

Every time I reinstall Windows, I lose the first afternoon deleting software I
never asked for — games, trial apps, tiles. Then another hour chasing down the
data collection that switched itself back on.

If you've done this, you know. If you're the one who fixes machines for your
parents, your lab, or your colleagues, you really know.

So I built the button I kept wishing for. It's called Shields Up — free,
open source, nothing to install:

🧹 Removes the preinstalled apps (you approve the list)

🛡 Sets the firewall sensibly without reading a single rule — and one button
puts everything back if something you need stops working

🚪 Closes the backdoors Windows ships with — VPN hooks, hidden hotspots,
kernel-debug access — and re-checks them every time you open the app, because
updates like to quietly reopen them

📵 Turns off each app's data collection using the vendor's own official
switch, then verifies it actually stopped calling home

Three things I want you to know before you run any software, including mine:

1. Every action asks first, and almost everything can be undone.
2. No installer, no account, no telemetry, nothing running in the background.
   Delete the folder and it's gone.
3. All of the code is public — you can read every line before you run anything.

It's free under Apache-2.0, built with care in California, works on Windows 10
and 11, and it's one download with no strings.

🔗 https://github.com/dparksports/shields-up

If you maintain machines for a classroom, a lab, an office, or a household —
or you just did a reinstall this weekend — I'd genuinely like your feedback.

## Notes for posting

- **First two lines are the hook** — LinkedIn truncates after ~3 lines; the
  "afternoon deleting software" line must land above the fold.
- **Attach one infographic** (Image 1 or 2 from the prompt file). Posts with a
  single strong square image outperform link-only posts; put the repo link in
  the post itself (link card) or first comment.
- **Reply to yourself** with the release-page link and the checksum line —
  the security-minded part of your network will appreciate that the hash is
  right there.
- Timing: Tuesday–Thursday morning (US) tends to reach professional feeds best.
- If a colleague asks "is it safe?" — point them at the README's
  *"Why should I run an app from a publisher I don't know?"* section; it was
  written for exactly that question.
